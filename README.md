Amazon Web Services (AWS) Internship

About the Internship
I have completed a  Amazon Web Services (AWS) internship
with EWB Edutech Private Limited. The internship focused on learning
cloud-computing fundamentals and gaining practical exposure to AWS
services, virtual servers, networking, and web-server deployment.
- Role: AWS Cloud Intern
- Organization: EWB Edutech Private Limited

Skills and Technologies Learned
Amazon Web Services (AWS)
 - Amazon EC2: Learned the fundamentals of launching and working
   with cloud virtual machines (instances).
 - Amazon VPC: Learned the basics of Virtual Private Clouds and
   cloud-network configuration.
 - AWS Services: Gained introductory, hands-on exposure to AWS
   services and how they support cloud infrastructure.
 - Web-server deployment: Practised the process of launching a web
   server on a cloud instance and making a web page available.
 - Cloud infrastructure basics: Developed an understanding of how
   compute resources and networking work together in AWS.
